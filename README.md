# 坦克大战 · Tank Battle

一个用原生 HTML5 Canvas + JavaScript 编写的经典坦克大战游戏。**单文件、零依赖、零构建**，双击 `index.html` 就能玩。

![单文件](https://img.shields.io/badge/单文件-index.html-ffd23f) ![依赖](https://img.shields.io/badge/依赖-0-42d9c8) ![许可证](https://img.shields.io/badge/license-MIT-blue)

## 在线试玩

开启 GitHub Pages 后即可在线游玩：`https://<你的用户名>.github.io/<仓库名>/`

## 玩法

驾驶坦克保卫画面底部的**基地（老鹰）**，消灭全部敌军坦克即可通关。基地被摧毁或生命耗尽则游戏结束。

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或 `↑` `←` `↓` `→` |
| 开炮 | `空格` |
| 暂停 / 继续 | `P` |
| 重新开始 | `R` |
| 静音开关 | `M` |

手机 / 平板会自动显示虚拟方向键与开炮按钮。

## 游戏要素

**地形**
- 🧱 **砖墙** — 可被炮弹摧毁
- ⬜ **钢板** — 普通炮弹无法破坏，满级火力（★★★）可击穿
- 🌊 **河流** — 坦克无法通过，炮弹可飞越
- 🌳 **树林** — 坦克可藏身其下，视觉遮挡
- 🦅 **基地** — 被摧毁即游戏结束

**敌军坦克**（4 种）

| 类型 | 生命 | 速度 | 分数 | 特点 |
| --- | --- | --- | --- | --- |
| 普通 (灰) | 1 | 慢 | 100 | 基础型号 |
| 快速 (蓝) | 1 | 快 | 200 | 机动性强 |
| 炮击 (橙) | 1 | 中 | 300 | 射速与弹速极高 |
| 装甲 (绿) | 4 | 慢 | 400 | 血量随受伤变黄 → 橙 → 红 |

**道具**（击毁闪烁的"奖励坦克"掉落）

| 道具 | 效果 |
| --- | --- |
| 星 | 火力升级（最多 ★★★，满级可击穿钢板） |
| 命 | 生命 +1 |
| 盾 | 10 秒无敌护盾 |
| 雷 | 立即摧毁场上全部敌军 |
| 钟 | 冻结敌军 8 秒 |
| 铲 | 基地围墙临时钢铁化 15 秒 |

## 关卡

内置 3 张手工设计的地图，通关后循环并逐关提升难度（敌军更多、强敌比例更高、刷新更快）。

## 技术实现

- **单文件架构** — HTML / CSS / JS 全部内联在 `index.html`，无外部资源、无网络请求
- **固定步长主循环** — 60 FPS 逻辑步进 + `requestAnimationFrame` 渲染，帧率无关，高刷屏与低配机表现一致
- **网格 + AABB 碰撞** — 16×16 瓦片地图，坦克转向时自动对齐格线，避免卡墙角；子弹分步推进防止高速穿墙
- **音效合成** — 使用 Web Audio API 实时合成开炮、爆炸、道具音效，无需任何音频文件
- **Canvas 程序化绘制** — 坦克、砖墙、钢板、水面、树木、基地、爆炸粒子全部由代码绘制，没有一张图片资源
- **响应式** — 桌面端键盘操作，移动端自动切换为触屏虚拟摇杆
